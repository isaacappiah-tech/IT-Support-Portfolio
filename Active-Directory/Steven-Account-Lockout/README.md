# Steven Han – Active Directory Account Lockout

## Incident
User was unable to log in to the Windows 10 client.

## Problem
Steven Han's Active Directory account was locked after multiple failed login attempts.

## Investigation
- Verified the login error on the Windows 10 client.
- Located Steven Han's account in Active Directory Users and Computers.
- Confirmed that the account was locked.

## Resolution
- Unlocked the user's Active Directory account.
- Reset the user's password.
- Created a new password.
- Verified successful login on the Windows 10 client.

## Verification
Steven Han successfully logged in to the Windows 10 client after the account was unlocked and the password was reset.

## Tools Used
- Windows Server 2022
- Active Directory Users and Computers
- Windows 10
- ServiceNow
- VMware
